## 📊 Overview

This project implements a **real-time facial expression recognition system** that detects and classifies human emotions from images and live webcam feeds. It combines **Haar Cascade classifiers** for efficient face detection with a **custom CNN architecture** for accurate expression classification.

### 🎯 Key Capabilities

| Feature | Description |
|---------|-------------|
| **Real-time Detection** | Process live webcam feeds at 30+ FPS |
| **7 Emotion Classes** | Angry, Disgust, Fear, Happy, Neutral, Sad, Surprise |
| **Face Detection** | Haar Cascade for fast, reliable face detection |
| **Image Preprocessing** | Gaussian filtering, edge detection, normalization |
| **Multiple Input Sources** | Webcam, static images, video files |
| **Confidence Scoring** | Probabilistic output with confidence thresholds |
